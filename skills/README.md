## Adding a New Skill

1. Create `your-skill-name/SKILL.md`
2. Add YAML frontmatter with `name:`, `description:`, `license:` and `metadata.author:`
3. Write your skill instructions
4. Add it to this table
5. Re-run `setup.sh` to install it

See [CONTRIBUTING.md](../CONTRIBUTING.md) for full guidelines.
